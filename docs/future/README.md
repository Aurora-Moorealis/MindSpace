# Tareas futuras

Ideas y trabajos pendientes que **todavía no se han empezado**. Cada archivo es
una tarea autocontenida: qué hay que hacer, de qué depende y cómo saber que está
terminada.

## Reglas de esta carpeta

- **Una tarea por archivo**, nombre en `kebab-case` descriptivo.
- Todo archivo lleva la misma cabecera: `Estado`, `Prioridad`, `Depende de`.
- Si una tarea se convierte en trabajo real, se especifica con OpenSpec
  (`openspec/changes/<change>/`) o se diseña con EGM (`docs/designs/<feature>.md`)
  y **se borra de aquí**. Esta carpeta no es un backlog eterno: es una lista de
  recordatorios viva.
- No dupliques contenido de `docs/designs/`: si algo ya está en el diseño formal,
  enlázalo en lugar de copiarlo.
